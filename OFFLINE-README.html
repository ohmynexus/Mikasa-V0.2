Catatan offline

Data transaksi disimpan di penyimpanan browser/perangkat. Buat backup JSON berkala, terutama sebelum membersihkan data browser atau pindah perangkat. Mode offline melalui instalasi PWA paling andal ketika aplikasi sudah dibuka sekali melalui HTTPS (misalnya GitHub Pages).

Font dapat jatuh ke font sistem saat offline. Impor XLSX memerlukan pustaka dari CDN jika tidak tersedia dalam cache; saat benar-benar offline, gunakan CSV. Jangan buka HTML langsung melalui file:// bila ingin memakai service worker.
